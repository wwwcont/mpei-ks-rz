# КС — расчётное задание под вариант

Генератор РЗ по курсу «Компьютерные сети» (НИУ МЭИ, ИВТИ, кафедра ВМСС, практикум Рыбинцева В.О., методичка 2026).

Вводишь ФИО, группу и вариант — получаешь **КМ-1…КМ-4 и полный РЗ** в docx и pdf:

| Файл | Что внутри |
| --- | --- |
| КМ-1 | задание 1 — СКС этажа |
| КМ-2 | задания 1–2 — + базовая ЛВС со STP |
| КМ-3 | задания 1–3 — + VLAN на интеллектуальных коммутаторах |
| КМ-4 | задания 1–4 — + VRRP, маршрутизация, DHCP |
| РЗ | всё вместе, титул «Расчётное задание» |

Каждая КМ содержит все предыдущие задания — методичка требует отправлять очередное задание вместе с предыдущими.

## Для студентов

**Всё через Issue, ничего ставить не нужно.**

1. **Issues → New issue → «Мой РЗ»**: ФИО полностью, группа, вариант, номер в журнале (для IP-адресов в задании 3;
   пусто — равен варианту) → создать.
2. Через пару минут бот ответит комментарием: ссылки на все КМ и РЗ (docx + pdf), что получилось (длины кабелей, стоимость
   задания 3 против бюджета), тема письма.
3. Поменять данные — отредактируйте форму Issue (или напишите `/пересобрать`), бот пересоберёт.

**Перед отправкой:** общие абзацы у всей группы из одного шаблона — перескажите их своими словами; числа, таблицы
и рисунки не трогайте. Дату сдачи на титуле впишите сами.

Оформление — по работе, принятой Рыбинцевым В.О.: титул по кафедральному шаблону (шапка и «Москва 20ХХ г.» в
колонтитулах, таблицы «Выполнил / Принял»), «Задание N» с подразделами «Исходные данные для проектирования»,
«Выбор необходимого оборудования», «Разработка сети», «Документация», подписи «Таблица N» и «Рис. N.»,
обозначения S12-01/S24-02 (задание 2), SS2L24-01/SS3L12-01 (задание 3), серверы File-server-main, DB-server-main,
WG-N-server. Схемы сетей — на альбомных страницах.

## Что генерируется

- **Задание 1.** Выбор центров коммутации среди допустимых мест плана: все статические соединения ≤ 90 м, минимум суммарной
  длины и так, чтобы задание 3 уложилось в бюджет. Розетки по каналам вдоль границ зон, панели по 24 порта, длины трасс
  по плану в масштабе L×W + 3 м, рисунок плана с ЦК, розетками и каналами, таблица статических соединений.
- **Задание 2.** Рост числа сотрудников (округление вверх), размещение групп по зонам, выбор S12TF/S24TF, звезда к корневому
  коммутатору + резервные связи между коммутаторами групп, роли портов STP (К/Н/Б) по ID, схема на изображениях коммутаторов
  из методички, таблицы размещения и динамических соединений.
- **Задание 3.** VLAN10–40 для групп, VLAN50 для общих серверов, SS12TG-L3 + минимальный по стоимости набор L2 в каждом ЦК,
  режимы U/T и номера VLAN прямо в полях изображений коммутаторов, IP-план 1xx.1yy.zz.0/24, таблица маршрутизации.
- **Задание 4.** R-01/R-02 в VLAN60 (172.31.1.0/29), параметры VRRP, маршрут по умолчанию на виртуальный маршрутизатор, DHCP.

Решения с выбором (какие места ЦК, как раскидать группы по зонам, VRID, приоритеты) детерминированно зависят от ФИО: у
одногруппников с одинаковым планом решения различаются, у вас при пересборке — те же.

## Локально

```sh
pip install -r requirements.txt
python3 -m ksgen --fio "Рязанцев Иоанн Васильевич" --group А-12-23 --variant 17   # → build/А-12-23/17/
```

PDF (нужен LibreOffice; скрипт обновляет содержание перед экспортом):

```sh
/Applications/LibreOffice.app/Contents/Resources/python scripts/to_pdf.py build/А-12-23/17/*.docx   # macOS
python3 scripts/to_pdf.py build/А-12-23/17/*.docx                                                 # Ubuntu (python3-uno)
```

## Что где лежит

| Путь | Что там |
| --- | --- |
| `data/variants/<группа>.yaml` | варианты группы (Приложение 1) — для новой группы добавить файл и пункт в форме Issue |
| `plans/` | планы этажей T1–T8, U1–U8 и `geometry.json` — оцифрованные зоны, контур здания, места ЦК |
| `docs/source/` | методичка 2026, варианты, изображения оборудования |
| `ksgen/` | генератор: `task1…task4` — расчёт, `draw_plan`/`draw_net` — рисунки, `report` — docx |
| `ksgen/faceplates.json` | координаты портов и полей VLAN/Port Mode на изображениях коммутаторов |
| `scripts/` | бот Issue, docx → pdf |
| `.github/workflows/rz.yml` | Issue → сборка → ветка `results` → комментарий |
